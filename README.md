\# 🌾 Farmer-Customer E-commerce Platform



A \*\*MERN-based\*\* full-stack web application that simplifies agricultural commerce by connecting \*\*Farmers\*\*, \*\*Delivery Partners\*\*, and \*\*Customers\*\* through a unified and intelligent digital platform.

\## 📌 About the Project



In traditional Agri-commerce, farmers rely heavily on intermediaries to sell their produce, which reduces profits and limits transparency. This platform eliminates intermediaries by providing a direct digital connection between all stakeholders.



The system integrates a \*\*CNN (Convolutional Neural Network)\*\* model that automatically recognizes and labels product images uploaded by farmers — reducing manual effort and improving accuracy.



\---



\## 🚀 Key Features



\### 👨‍🌾 Farmer Module

\- Register \& Login securely

\- Upload product images with price \& quantity

\- CNN model auto-labels uploaded products

\- Assign delivery partners to orders

\- View transaction history \& earnings



\### 🛒 Customer / User Module

\- Register \& Login

\- Browse categorized products

\- Add to cart \& place orders (dummy payment gateway)

\- Track orders in real-time

\- View order history



\### 🚚 Delivery Partner Module

\- Register \& Login

\- View assigned orders

\- Update delivery status: `Picked Up → Shipped → In Transit → Out for Delivery → Delivered`

\- Real-time status reflected to customers

\## 🔧 How to Run the Project



\### 1️⃣ Clone the Repository

```bash

git clone https://github.com/YOUR\_USERNAME/Farmer-Customer-E-commerce-Platform.git

cd Farmer-Customer-E-commerce-Platform

```



\### 2️⃣ Run the Backend

```bash

cd backend

npm install

npm start

```



\### 3️⃣ Run the Frontend

```bash

cd frontend

npm install

npm start

```



\### 4️⃣ Open in Browser

```

http://localhost:3000

```



> ⚠️ Make sure \*\*MongoDB\*\* is running on your system before starting the backend.

\## 📊 Modules Overview



\### 🔐 Authentication

All three roles (Farmer, Delivery Partner, Customer) have separate secure login and registration. Each role is redirected to their own dashboard after login.



\### 🤖 CNN-Based Product Recognition

When a farmer uploads a product image, the CNN model processes it and automatically generates a label — reducing manual classification effort and errors.



\### 📦 Order Management

Customers can browse, cart, and order products. Farmers can track and assign deliveries. Delivery partners update live statuses.



\### 📍 Real-Time Delivery Tracking

Status updates from delivery partners are instantly reflected on the customer's order tracking page.

\## 💡 Problem Statement



Traditional Agri-commerce models have:

\- No direct digital platform for farmers to sell produce

\- No real-time order or delivery tracking

\- Manual and error-prone product entry

\- Fragmented communication between stakeholders

\- Dependency on intermediaries reducing farmer profits



This platform solves all of the above. ✅
